你写下的每一行代码，
都会变成知识。

每次用 Claude Code 写代码，Vibe Knowledge 都会在后台默默把发生的一切，转换成通俗易懂的闪卡。 不需要额外操作，也不用再打开一个新应用。

需要 Claude Code。安装 hooks 和 MCP server 只需不到30秒，无需注册云端账号。

使用流程

01

照常开发

像平时一样用 Claude Code 写代码就行。Vibe Knowledge 会自动挂钩到每一次 Edit、Write、Bash 调用上，不需要针对每个项目单独配置。

02

闪卡悄悄生成

每次会话结束后，后台程序会问 Claude Haiku："这次我们碰到了什么概念，用大白话怎么说？"闪卡就这样诞生了。整个过程完全不会拖慢你的开发速度。

03

复习、重复、记住

按项目浏览、搜索术语表、查看概念图，或者做一次间隔重复测验。用自己的话讲出来，谈客户的时候也不会卡壳。

闪卡长什么样

永远说人话，
不说术语。

每张卡片都会记录术语、使用原因和一个生活化的类比 — 全部自动从你实际写的代码中提取。

写一周代码之后，你就会拥有100多张卡片，每一张都来自你自己的项目。

Webhook
网络钩子
在某件事发生的瞬间，自动通知另一个系统的方式。
在 Stripe 完成支付的那一刻通知服务器 — 不需要轮询。
就像门铃。有事发生就按一下，家里有人就会来开门。

都包含什么

自动采集

悄悄挂钩后台

只需安装一次，所有项目都能用。采集用的 hook 以毫秒级运行，从不调用 AI — 采集这一步零延迟、零成本。

隐私优先

敏感信息不会离开你的电脑

API 密钥、token、.env 文件内容，在存储前都会被自动屏蔽。像 sk-...、ghp_...、Bearer ... 这样的模式，在采集的瞬间就会被打码。

SM-2 测验

内置间隔重复

内置了基于遗忘曲线的测验。给自己打分（"忘了 / 有点模糊 / 记住了"），算法会自动安排下一次复习时间。

概念图

看清知识之间的联系

把你最常用的40个术语，用力导向图直观呈现。发现知识的聚类，找出理解薄弱的地方，看着自己的认知慢慢生长。

MCP Server

在 Claude Code 里直接查自己的知识

添加为 MCP Server 后，可以在会话里直接问"我学过哪些关于 webhook 的知识？"。积累的闪卡，变成一个可检索的第二大脑。

本地查看器

离线可用，零依赖

用浏览器打开 view/index.html 就行，不需要服务器、打包工具，也不需要联网。所有数据都保存在 ~/.claude/vibe-knowledge/data/ 里。

你的代码，
始终留在你自己的电脑上。

所有数据都保存在 ~/.claude/vibe-knowledge/data/，不会传输到任何服务器。

闪卡生成（distill）过程不需要你的 ANTHROPIC_API_KEY — 用的是 Claude Pro 订阅额度，不会产生额外的 API 调用费用。

  • API 密钥和 token 在存储前都会被替换成 [secret masked]
  • .env、*.pem、*.key 文件的内容不会被记录
  • password=、Bearer ...、JWT token 会被自动屏蔽
  • 开源 — 采集逻辑的每一行代码都可以在 GitHub 上审查
  • 没有埋点、没有遥测、不需要注册账号
